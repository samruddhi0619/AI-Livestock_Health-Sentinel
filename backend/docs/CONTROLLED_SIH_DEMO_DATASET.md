# Controlled SIH Demonstration Dataset Specification

## Overview

The **Controlled SIH Demonstration Dataset** provides deterministic, realistic seed telemetry for evaluating the **AI-Livestock Health Sentinel** platform during Smart India Hackathon (SIH) demonstrations, peer audits, and stakeholder walkthroughs.

All records generated by this dataset are explicitly tagged with standardized internal metadata to guarantee transparency, data provenance, and **strict isolation from actual ML model training pipelines**.

---

## 1. Internal Telemetry & Provenance Metadata

Every single entity (User, Animal, Health Record, Vaccination, Disease Report, AI Assessment, Alert, Cluster) persisted by the seed generator carries the following mandatory internal labels:

```json
{
  "is_simulated_demo": true,
  "is_prototype_demo": true,
  "data_provenance": "Simulated Prototype SIH Dataset",
  "dataset_label": "SIMULATED_DEMO_SIH_2026",
  "ml_training_eligible": false,
  "disclaimer": "Simulated prototype data for SIH demonstration only. Not for ML model training or official veterinary reporting."
}
```

### ML Data Isolation Safeguard
- **`ml_training_eligible: false`**: Real-world machine learning training pipelines, feature stores, and model evaluation routines filter out any record where `ml_training_eligible == false` or `is_simulated_demo == true`.
- **Zero Pollution**: Prevents synthetic prototype scenarios from biasing live production computer vision or spatio-temporal risk forecasting models.
